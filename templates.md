## Evidence Preservation Checklist

### Digital Evidence
- [ ] System logs extracted and dated
- [ ] Screenshots with timestamps taken
- [ ] Email headers preserved
- [ ] Network logs collected
- [ ] File metadata documented
- [ ] All evidence stored securely (encrypted/password protected)
- [ ] Multiple copies in different locations
- [ ] Chain of custody documented

### Physical Evidence
- [ ] Pay stubs and salary documentation collected
- [ ] Contracts/agreements secured
- [ ] Notebooks/notes of incidents archived
- [ ] Business cards/contact info saved
- [ ] Calendar entries documented

### Legal Documents
- [ ] Employment contract
- [ ] Job offer letter
- [ ] Handbook/policy documents
- [ ] Email chains printed/saved
- [ ] Text message screenshots
- [ ] Performance reviews
- [ ] Any written warnings or communications
